# Daily Writer Status Bot

Telegram-бот на Python, который ежедневно проверяет информацию о выбранном писателе через API Википедии и отправляет уведомление в Telegram.

## Возможности

- получение информации через API Википедии;
- обработка JSON-ответов;
- автоматическая ежедневная отправка сообщений;
- работа с Telegram Bot API.

## Стек

- Python
- Telegram Bot API
- REST API
- JSON
